# Phase 1 Execution Plan (post-redefinition) + Compute Reality Check

Date: 2026-06-28 · Related: ADR-001
Target: FKBP12 (P62942) — small molecule restoring the BMP signaling axis

## Compute Reality (honest constraints)
This workstation = macOS (Apple Silicon), no GPU cluster. Therefore:

| Task | Local? | Note |
|---|---|---|
| Experimental structure collection (PDB) | ✓ | FKBP12 has abundant experimental structures → low AF3 dependence |
| Pocket detection (fpocket) | ✓ | conda install |
| Cheminformatics (RDKit) | ✓ | ligand handling, filters, properties |
| Docking (AutoDock Vina/smina) | ✓ (small scale) | candidate evaluation |
| Short MD (OpenMM, CPU) | △ | demo/validation only; 100 ns is unrealistic locally |
| AF3 inference | ✗ | needs GPU/Linux. AF Server (web) or cluster offload |
| Large-scale diffusion generation (DiffSBDD) | ✗ | needs GPU cluster (matches proposal's A100×8 line) |
| RL iterative optimization (REINVENT4) | ✗ | needs GPU |

Principle: **do locally what can be done locally**; for GPU-bound steps, prepare inputs/interfaces to the point where they can be handed to a cluster (no vaporware).

## Phase 1 goals → verification criteria
1. **Build target dossier** → verify: a document with UniProt/PDB IDs, sequence, and binding-pocket residues exists
2. **Collect & clean experimental structures** → verify: representative FKBP12 structures (apo + FK506 complex) saved as PDB in `data/raw/`
3. **Quantify the binding pocket** → verify: pocket volume, hydrophobicity, residue list computed (conditioning input for the generative model)
4. **Define selectivity counter-target panel** → verify: list of calcineurin (PPP3CA) / FKBP-family structures + comparison criteria
5. **Cheminformatics env & data pipeline** → verify: reproducible env imports RDKit; ChEMBL FKBP12 ligand collection script runs
